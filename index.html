Abstract

Retrieval-augmented generation reduces the hallucinations of large language models on chemistry questions, but static top-k retrieval adds topically related yet irrelevant passages and gives the model no signal for when the evidence is sufficient. We present ChemMA, a multi-agent framework that answers chemistry questions with tools. ChemMA first grounds the query into validated chemical entities, then a Planner builds a dependency graph of tool calls, and an Executor runs these calls and writes the relevant facts into a shared structured memory. A Constraint Verifier ends the loop only when the facts are sufficient and chemically valid, and a Consistency Evaluator checks the final answer against them.

Across MMLU-Chem, SciBench, and ChemBench4K, ChemMA raises the average accuracy of Llama-3.1-8B from 24.48% to 46.01%, and with Qwen-2.5-7B reaches 50.44%—surpassing GPT-4o without tools (46.35%). On Mol-Instructions, generated molecule validity increases from 0.47–0.65 to 0.95–0.99.

Framework Overview

ChemMA formulates chemical question answering as an iterative, constraint-aware decision process over 13 deterministic cheminformatics, computation, retrieval, and lookup tools coordinated via a shared Structured Memory.

1. Chemical Grounding

Separates hard structural validation (Regex + RDKit) from soft entity extraction to initialize verified query entities.

2. Dependency Planning

Constructs a DAG of atomic tool calls under chemical preconditions so independent steps execute in parallel.

3. Action Execution

Adapts tool queries, executes Python/RDKit/PubChem calls, and distills raw observations into atomic facts.

4. Dual Verification

Constraint Verifier checks sufficiency & chemical invariants (e.g., valency, atom balance); Consistency Evaluator synthesizes the final answer.
